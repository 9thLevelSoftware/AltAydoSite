  3. Modify the `animate` function to accept a timestamp parameter (requestAnimationFrame provides this):
     ```typescript

       animationFrameId = requestAnimationFrame(animate);

       lastFrameTime = timestamp - (elapsed % FRAME_INTERVAL); // Prevent drift

       // ... existing draw calls (clearRect, drawStars, drawNebulas, etc.)
     };
     ```
  4. Start with: `requestAnimationFrame(animate);` (the browser passes timestamp automatically)
