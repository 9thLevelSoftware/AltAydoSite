  <action>
Extract the inline notification pattern from MissionTemplateCreator.tsx (lines 66-69 state, 559-586 render) into a reusable toast system with three parts:

**MobiGlasToast.tsx** - Individual toast component:
- Props: `{ id: string; type: 'success' | 'error' | 'info' | 'warning'; message: string; onDismiss: (id: string) => void }`
- Use framer-motion for enter/exit: `initial={{ opacity: 0, x: 100, scale: 0.8 }}`, `animate={{ opacity: 1, x: 0, scale: 1 }}`, `exit={{ opacity: 0, x: 100, scale: 0.8 }}`
- Icon per type: checkmark (success), X circle (error), info circle (info), warning triangle (warning)
- Color per type using CSS vars: `--mg-success` (success), `--mg-danger`/`--mg-error` (error), `--mg-primary` (info), `--mg-warning` (warning)
- Close button (X) calling onDismiss
- Style: dark panel background matching `--mg-panel-dark`, border using type color at 0.3 opacity, rounded corners
- Match the existing MissionTemplateCreator notification styling (backdrop-blur, shadow)

**MobiGlasToastProvider.tsx** - Context provider:
- Create `ToastContext` with value `{ addToast: (type, message, duration?) => void; removeToast: (id) => void }`
- Maintain toast queue in state as `Toast[]` where `Toast = { id: string; type; message; duration }`
- Use `crypto.randomUUID()` for toast IDs (NOT Math.random)
- Auto-dismiss via useEffect: for each toast, set timeout for `duration` (default 5000ms), clear on unmount
- Render toast container as fixed-position div: `fixed top-20 right-6 z-[9999] flex flex-col gap-3`
- Wrap toasts in `AnimatePresence` for exit animations
- Max 5 visible toasts; if more queued, remove oldest

**useToast.ts** - Consumer hook:
- Consume ToastContext
- Return object with convenience methods: `{ toast: { success(msg, duration?), error(msg, duration?), info(msg, duration?), warning(msg, duration?) } }`
- Throw descriptive error if used outside provider

Do NOT use `sonner` or any external toast library -- build from existing codebase patterns.
