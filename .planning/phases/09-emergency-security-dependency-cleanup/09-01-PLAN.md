  <action>
1. FIX CRON AUTH in all three cron endpoints (discord-sync, ship-sync, warm-images). Each has identical fail-open pattern. Replace with fail-closed:

   BEFORE (vulnerable -- skips auth if CRON_SECRET not set):
   ```typescript
   const cronSecret = process.env.CRON_SECRET;
   if (cronSecret) {
     const authHeader = request.headers.get('authorization');
     if (authHeader !== `Bearer ${cronSecret}`) {
       return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
     }
   }
   ```

   AFTER (fail-closed -- rejects if CRON_SECRET not configured):
   ```typescript
   const cronSecret = process.env.CRON_SECRET;
   if (!cronSecret) {
     console.error('[cron] CRON_SECRET not configured - rejecting request');
     return NextResponse.json({ error: 'Server misconfigured' }, { status: 503 });
   }
   const authHeader = request.headers.get('authorization');
   if (authHeader !== `Bearer ${cronSecret}`) {
     return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
   }
   ```

2. FIX assign-synced-role 401 response (SEC-15). In `src/app/api/discord/assign-synced-role/route.ts`:
   - Remove the entire `debug` object from the 401 response (it leaks `cronSecret.substring(0, 3)` and `receivedHeader`)
   - Also fix the cron auth path in this file to use fail-closed pattern (same as above) if it has the same fail-open pattern
   - Return only `{ error: 'Unauthorized' }` with status 401

3. FIX FINANCE DB (SEC-14). Two locations:
   - `src/app/api/finance/transactions/route.ts` line ~110: Change `const { client } = await connectToDatabase(); const db = client.db();` to `const { db } = await connectToDatabase();`
   - `src/lib/finance.ts` line ~22: Same fix -- use `const { db } = await connectToDatabase();` instead of `client.db()`

   The `connectToDatabase()` function already returns `{ client, db }` where `db` is `client.db(process.env.COSMOS_DATABASE_ID)`. Using `client.db()` without args gets the wrong default database.
