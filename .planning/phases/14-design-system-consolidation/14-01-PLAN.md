  Modify MobiGlasButton.tsx to address three pre-existing issues:

  1. **Add `success` variant**: Add to the variant union type and variantStyles map:
     - `success: 'mg-button border border-[rgba(var(--mg-success),0.5)] text-[rgba(var(--mg-success),1)] hover:bg-[rgba(var(--mg-success),0.2)] hover:border-[rgba(var(--mg-success),0.8)]'`
     - This matches the pattern of existing variants and maps to the green --mg-success CSS variable.

  2. **Widen onClick type**: Change from `onClick?: () => void` to `onClick?: (e?: React.MouseEvent<HTMLButtonElement>) => void`. This allows both `() => doSomething()` and `(e) => { e.preventDefault(); doSomething(); }` patterns that exist in the codebase.

  3. **Add HTML attribute passthrough**: Change the interface to extend both MotionProps AND pick essential ButtonHTMLAttributes. Add these HTML attributes to the interface:
     - `id?: string`
     - `name?: string`
     - `form?: string`
     - `aria-label?: string` (use `ariaLabel` field name, map to `aria-label` on the element)
     - `tabIndex?: number`
     - `title?: string`
     Pass these through to the motion.button element via explicit props (NOT via ...motionProps spread, which would conflict).

  Do NOT change any existing variant colors, sizes, or animation behavior.
  Do NOT touch the mg-button CSS class usage yet (that's Plan 07).
  </action>

  Create `MobiGlasFormError.tsx` — a standardized form-level error banner component for DS-05 tier 2.

  **Props interface (MobiGlasFormErrorProps):**
  - `message: string` — The error message to display
  - `details?: string` — Optional additional details (shown below message in smaller text)
  - `onDismiss?: () => void` — Optional dismiss callback (shows X button if provided)
  - `className?: string` — Optional additional classes

  **Implementation:**
  - Use `'use client'` directive (uses motion for animation)
  - Import `motion` from `motion/react` and `AnimatePresence` for enter/exit
  - Wrap in `AnimatePresence` — only render when `message` is truthy
  - Use `motion.div` with `initial={{ opacity: 0, y: -10 }}`, `animate={{ opacity: 1, y: 0 }}`, `exit={{ opacity: 0, y: -10 }}` for smooth enter/exit
  - Container: `role="alert"` for accessibility, classes: `relative p-3 border border-[rgba(var(--mg-danger),0.5)] bg-[rgba(var(--mg-danger),0.1)] text-[rgba(var(--mg-danger),0.9)]`
  - Error icon: Use an inline SVG exclamation triangle (or circle-exclamation), 16x16, `fill="currentColor"`
  - Layout: flex row with icon on left, message text on right, dismiss button far right
  - Font: `text-sm tracking-wider` to match MobiGlas aesthetic
  - Details: `text-xs opacity-70 mt-1` below the message
  - Dismiss button: `text-[rgba(var(--mg-danger),0.6)] hover:text-[rgba(var(--mg-danger),1)]`, simple X character

  **Add to barrel exports in index.ts:**
  - `export { MobiGlasFormError } from './MobiGlasFormError';`
  - `export type { MobiGlasFormErrorProps } from './MobiGlasFormError';`
