**Step 3: Rewrite useUserProfile.ts to server-first:**

Replace the entire hook implementation. The new hook must:

**Load flow:**
```
1. If no session -> return null profile, isLoading false
2. If session exists -> fetch GET /api/profile
3. On success -> merge response with defaults, set profile, store __v for optimistic locking
4. On fetch failure -> fall back to localStorage (versioned key: `user_profile_v1_${email}`)
5. On localStorage miss -> create default profile from session data
6. Set isLoading false after any path completes
```

**Save flow (updateProfile function):**
```
1. Optimistically update local state immediately
2. Write to localStorage as cache (write-through)
3. Map field names: subsidiary -> division (for API), keep preferredGameplayLoops as-is
4. PUT /api/profile with { ...mappedUpdates, __v: currentVersion }
5. On success -> update __v from response
6. On 409 Conflict -> re-fetch from server, show toast.info("Profile was modified elsewhere -- refreshed")
7. On other error -> show toast.error("Failed to save profile")
8. Do NOT revert optimistic state on error (localStorage cache preserves intent)
```

**Field mapping between UserProfile (client) and User (server):**
- `subsidiary` (client) <-> `division` (server): Map on save and load
- `handle` (client) <-> `aydoHandle` (server): Read from session, don't send to API
- `name` (client): Derived from session `aydoHandle`, don't send to API
- `email` (client): From session, don't send to API
- `photo`, `payGrade`, `position`, `timezone`, `preferredGameplayLoops`, `ships`: Direct mapping

**One-time localStorage migration:**
- On first server load, if server `preferredGameplayLoops` is undefined/empty BUT localStorage has values, PUT the localStorage values to server
- After successful migration, clear the old localStorage profile key
- This handles the transition period for existing users

**Import useToast** from `@/hooks/useToast` for error/conflict notifications.

Keep the hook's return type identical: `{ profile: UserProfile | null; isLoading: boolean; updateProfile: (updates: Partial<UserProfile>) => void }`
