**escort-requests/route.ts DELETE handler:** Same pattern but stricter:
1. Use `requireAuth()` from auth-guards
2. Look up the escort request by ID
3. Check ownership: only creator or leadership can delete (assigned officer cannot delete, only modify)
4. Return 403 if not authorized

Follow the pattern already established in `planned-missions/route.ts` which has `canUserModifyMission()` and `canUserDeleteMission()` checks.
